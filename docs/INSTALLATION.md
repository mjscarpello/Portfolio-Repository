# Installation — Extraordinary Final Portfolio Release

## If you are replacing your current GitHub Pages site

1. Download or back up your current repository contents.
2. Extract this release ZIP.
3. Upload **all** extracted files and folders to the root of your `Portfolio-Repository` repository.
4. Make sure hidden items such as `.github` remain included.
5. Commit the changes.
6. If your site already uses the Lab Rat release workflow, keep **GitHub Pages → Source = GitHub Actions**.
7. Wait for the Pages/Actions deployment to finish.
8. Hard refresh your browser (`Cmd + Shift + R`) if the previous version still appears.

## Important note
This release still depends on the GitHub Actions workflow because the playable Lab Rat game is stored as a packaged game source and expanded during publishing.

# Start here: upload the entire portfolio in one GitHub website commit

1. Save a backup of your existing repository from **Code → Download ZIP**.
2. Unzip the `Portfolio-Repository-Organized-Collections.zip` file.
3. Open https://github.com/theOrdinaryi/Portfolio-Repository on the `main` branch, **at the repository root**.
4. Choose **Add file → Upload files**.
5. Drag **the contents of the unzipped package**, not the enclosing folder. You should see `index.html` alongside the `school/`, `work/`, `personal/`, and `figures/` folders. Never create an extra `Portfolio-Repository-main 2` or other enclosing folder.
6. Commit directly to `main` with summary `Organize portfolio and add original ERCOT charts`.
7. Check GitHub Pages in Settings → Pages and the deployed site at https://theordinaryi.github.io/Portfolio-Repository/ .

Full step-by-step instructions with troubleshooting: `docs/GITHUB-INSTALLATION.md`.

The ZIP contains 14 **original**, not regenerated, graphs: 4 from the NOAA team presentation and 10 from the uploaded ERCOT executed notebook. The other project galleries stay free of fake results or graphics.

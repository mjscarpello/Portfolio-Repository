DSC 450 / PROJECT 03 / PLANNED CLASSIFICATION

Recycling contamination
risk predictor.

An upcoming investigation into whether available collection and material characteristics can help identify potential contamination in recycling systems.

Expected role Data WranglerTeam DSC 450 · Group 1Status Planned / not yet evaluated

THE QUESTION

What makes a contamination risk measurable?

Contaminated recyclables can create challenges for sorting and recovery operations, but useful predictions require an outcome the data actually measures. Before modeling, the team will need to define contamination, identify records available before that outcome is known, and evaluate the source's limitations.

As Data Wrangler, my planned role involves inspecting the available dataset, documenting missingness, standardizing meaningful fields, and preparing reliable inputs for modeling. This page records the project direction without pretending results already exist.

PROPOSED WORKFLOW

From source records to useful evidence.

01 / SOURCE

Confirm the dataset

Document provenance, unit of observation, coverage, and whether outcomes are directly observed or inferred.

02 / PREPARATION

Make cleaning decisions visible

Inspect duplicate records, inconsistent category labels, missing values, and variables that reveal the answer after the fact.

03 / MODELING

Define a fair test

Establish the contamination target, sensible reference model, evaluation split, and error metrics appropriate to the decision.

04 / IMPACT

Explain practical trade-offs

Discuss false alarms, missed contamination, and the limits of transferring any results to different facilities or regions.
